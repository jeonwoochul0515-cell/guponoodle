# 성인 원데이 쿠킹클래스 — 전체 정리 (2026-08-17)

## 무엇을 하는 프로젝트인가
어린이 체험 중심이던 구포국수체험관에 **성인 대상 저녁 원데이 쿠킹클래스**를 새 수익원으로 붙인다.
메뉴는 미니 치미창가 + 오븐 갈릭버터쉬림프. 만든 걸 그 자리에서 저녁으로 먹고, 도보 1분 밀당브로이에서 수제맥주 한 잔으로 마무리한다.

| | 개인·커플 | 회사 단체·팀빌딩 |
|---|---|---|

| 소요 | 90분 | 90분 |
| 인원 | 회차 정원 16명, 1회 최대 8명, 최소 1명 예약 가능 | 10~30명 |

## 핵심 발견 (전략 근거)

- **"팀빌딩"으로는 검색이 안 된다.** 부산팀빌딩 월 10건 vs 부산원데이클래스 3,490건.
  ⇒ 검색·광고는 "원데이클래스"로, 팀빌딩은 기업 직접 영업(전화·팩스)으로.
- **부산이색데이트 월 2,120건** — 커플 수요가 크다. 그래서 개인 상품을 커플·1인까지 넓혔다.
- **예약자 명단은 광고에 못 쓴다.** 다운로드 엑셀은 전화번호가 뒷4자리만 남는 마스킹 + 네이버 약관상 마케팅 사용 금지.
  ⇒ 재방문 홍보의 합법 경로는 **톡톡 마케팅메시지 + 알림받기 동의 고객**뿐.

## 사장님이 하셔야 할 일 (순서대로)

1. **[급] 네이버 예약 상품 2개 등록** — 개인(금·토), 단체(수·목). 좌석유형 "가격 선택 형".
   - 개인 상품 9월 회차까지 채우기 (지금 8/28·8/29 두 개뿐)
   - 1회 예매 최대 8개 설정
2. **[급] 톡톡 마케팅메시지 발송** — 최근방문 1,193명, 무료 1,105건. 개인용 문안 사용.
   - 무료 한도(1,105) < 대상(1,193)이라 초과분 비용 확인 후 발송
   - 위 1번을 먼저 끝내고 보낼 것 (예약할 상품·날짜가 있어야 함)
3. **스마트플레이스 대표키워드 3개 교체** — 어린이체험·북구체험·부산아이랑 → 부산원데이클래스·부산어린이체험·부산쿠킹클래스. (기본정보 수정 주5회 제한 주의)
4. **답 안 한 톡톡 상담 132건 확인**
5. **예약 상품 주소 회신** → 홈페이지 버튼을 실제 상품으로 연결(현재 임시로 플레이스 예약창)
6. **밀당브로이 맥주 단가·정산주기 문서화** (구두 협의만 된 상태)
7. **3~4일 뒤 광고 성과 점검** — 신규 소재 CTR, 플레이스 입찰 3배 효과
