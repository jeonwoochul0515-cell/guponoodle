- [x] **`/class`·`/date` 일정 데이터에 `startDate`가 없어 무효였다** — 2026-09-01 시작,
      매주 금 19시·토 18시 1시간 30분 반복(`eventSchedule`)으로 적었다. 날짜는 대표 확인.
- [x] **휴대폰 메뉴** — 세 가지가 겹쳐 있었다. ①내용이 화면보다 길면 스크롤이 막혀 맨 아래 예약 버튼에
      닿지 못했다(`justify-center` + `overflow` 기본값). ②카카오 버튼(z-46)과 하단 CTA(z-45)가 메뉴(z-40)를 덮었다.
      ③스크롤하면 메뉴 글자가 투명한 헤더 로고와 겹쳐 보였다.
      → `overflow-y:auto` + `justify-content:safe center`, 메뉴 열림 중 떠 있는 버튼 숨김, 상단 가림막(`.mm-shield`).
      실측: 화면 560px에서 스크롤 여유 113px, 끝까지 내리면 예약 버튼이 화면 안(520<560). 780px에서는 스크롤 불필요.
